Repeval logo

"Reval" inside a triangle. The R is the repository and "eval" is what Repeval does to it, so the word is the product's name in five letters. The three corners stand for the three things every run does: analyze, test, report.

The logo

The word is Archivo ExtraBold, the site's own face, converted to shapes. The R takes the text color, "eval" is the brand teal. The triangle stops short of the word on both sides so the word sits in the frame instead of on top of it.

Three corners, three steps

Analyze Test Report

Analyze

Repeval reads the repo: the stack, pages, API endpoints and functions.

Test

It writes Vitest and Playwright tests and runs them in a real browser.

Report

It hands back a screenshot of every page and explains each result in plain words.

Small spaces

"Reval" is too small to read below about 40 pixels, so headers, tabs and app icons use the triangle with just the R, next to the full name.

Favicon and app icon

The favicon puts the small mark on a dark tile, so it reads on light and dark browser tabs. The app icon is a full square because phones round the corners themselves.

Using it

Full logo

Use the Reval triangle where it can be at least 64 px tall: the hero, the README, social images.

Small mark

Below that, use the triangle with the R. Next to text, pair it with the word "repeval".

Clear space

Leave at least a quarter of the triangle's height empty around it.
